# Album Review Website

A Flask-based web application that allows users to view and review albums using data from the Spotify Web API.

## Features

- Dynamic album review pages
- Spotify API integration
- Automatic album artwork retrieval
- Dominant color extraction from album covers
- Dynamic album-themed backgrounds

## Technologies Used

- Python
- Flask
- HTML/CSS
- Jinja2
- Spotify Web API
- Spotipy
- Pillow

## Future Improvements

- User album search
- User accounts
- Database for storing reviews
- Rating system
